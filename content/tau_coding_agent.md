Let it be known that my coffebar / order ahead name is Tau / Tau
Aleph. Despite all the acclaim 𝛑 receives, 𝝉 is [twice as
nice][tauday].

Also, you’d be surprised how many different pronunciations of tau
there are in the world.

And so it is that while I have [much admiration][pi-agent-post] for
the [pi coding agent][pi-coding-agent], my go to when I get fed up
with Claude and Codex, enthusiasm was pegged at max when I heard of
the [tau coding agent][tau-coding-agent].

> Tau is a small Python coding agent you read like a textbook. Watch
> it stream model output, call tools, manage sessions, and grow into a
> terminal UI — one readable layer at a time. 
>
> No hidden machinery. Every moving part is on the page.

On one hand, tau clearly has much more modest goals than pi. On the
other, the harness is written in Python as opposed to TypeScript. That
right there makes it more accessible to me. It also appeals a bit to
my inner [Schemer][little-schemer]. A small minimalist framework,
constructed from first princples, designed for pedagogical purposes,
but ultimately extremely powerful. What’s not to like?

Yet another harness arrow in the quiver.
