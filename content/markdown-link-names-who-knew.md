I’ve been using [Markdown][markdown-wikipedia] for well over a decade now. How
did I only recently learn that link reference names weren’t limited to numbers
🙄?

From the [official markdown syntax documentation][markdown]:

> Link definition names may consist of letters, numbers, spaces, and
> punctuation — but they are not case sensitive.

And even better, a convenient shortcut:

> The implicit link name shortcut allows you to omit the name of the link, in
> which case the link text itself is used as the name. Just use an empty set of
> square brackets

The Markdown processor I use goes one step further. You can leave out the
empty square brackets as well.

Boy, does that improve readability!
